H2, now on .NET

H2Sharp brings the legendary Java H2 engine to C#. A usable subset runs end to end: an ADO.NET provider over an in-memory engine — DDL, DML, SELECT with GROUP BY, UNION, ordering and aggregates, parameters — measured against the reference H2 on the JVM. JOIN, subqueries and window functions are not ported yet, and a class that parses a statement but cannot execute it refuses loudly instead of answering wrongly.

Quickstart

A real query today, through Dapper over IDbConnection:

using H2Sharp.Data;

using IDbConnection con = new H2Connection("jdbc:h2:mem:demo");
con.Open();
con.Execute("CREATE TABLE PERSON(ID INT PRIMARY KEY, NAME VARCHAR)");
con.Execute("INSERT INTO PERSON VALUES(@Id, @Name)", new { Id = 1, Name = "Ada" });

var rows = con.Query<Person>("SELECT * FROM PERSON");

Build and test the port:

dotnet build H2Sharp.sln
dotnet test

NuGet ships with the provider phase:

# not published yet — name reserved
dotnet add package H2Sharp --prerelease
