Extensions available

The host-side extension surface: scalar UDFs, user-defined aggregates, hash algorithms, triggers, random and UUID generators. Registration happens on a closed connection (or a data source) before it is opened; opening takes an immutable snapshot, so an active session is never reconfigured. This is the .NET extension surface, not SQL CREATE ALIAS — the embedded engine stores no executable code (D-037).

Scalar UDFs

using var con = new H2Connection("Data Source=mem:demo;Storage=Memory");
((IH2Extensions)con).RegisterUdf<int, int>("DOUBLE_IT", x => x * 2, deterministic: true);
con.Open();
int v = con.QuerySingle<int>("SELECT DOUBLE_IT(21)");  // 42

RegisterUdf is provided for 0–4 arguments. The CLR types must have an SQL value mapping; RegisterHashAlgorithm registers a factory returning a fresh HashAlgorithm per call.

User-defined aggregates

((IH2Extensions)con).RegisterAggregate("MY_SUM", new MyAggregateProvider());
con.Open();
var rows = con.Query<int>("SELECT MY_SUM(x) FROM T");

Public types: IH2Aggregate, IH2AggregateProvider, AggregateProvider, AggregateProvider<T>, IH2MergeableAggregate, AggregateBase, CollectingAggregateBase, AggregateOptions. DISTINCT, FILTER and OVER go through the standard aggregate machinery. The package H2Sharp.Extensions ships ready-made aggregates — H2_STRING_AGG, H2_GEOMETRIC_MEAN, H2_PRODUCT, H2_HARMONIC_MEAN, H2_WEIGHTED_AVERAGE, H2_COUNT_IF — registered with RegisterH2Aggregates().

Hash algorithms and optional providers

((IH2Extensions)con).RegisterHashAlgorithm("MY_HASH", () => SHA256.Create());
con.Open();
var h = con.QuerySingle<byte[]>("SELECT HASH('MY_HASH', 'abc')");

BCL algorithms (MD5, SHA-1, SHA-256/384/512, SHA3-256/384/512) are registered automatically. Optional packages add more: H2Sharp.Hashes (SHA-224, BLAKE2/3, Keccak, … via UseH2Hashes()), H2Sharp.Crypto (AES/XTEA/FOG for ENCRYPT/DECRYPT via UseCrypto()), H2Sharp.JavaLegacy (JDK RAND sequence and ORA_HASH via UseJavaLegacy()). UUID v4 uses Guid.NewGuid, v7 uses Guid.CreateVersion7 on .NET 9+.

Triggers

var ds = H2ProviderFactory.Instance.CreateDataSource("Data Source=mem:demo;Storage=Memory");
ds.RegisterTrigger("TRG",
    (schema, table) => table == "PERSON",
    H2TriggerEvent.Insert | H2TriggerEvent.Update,
    before: false, rowBased: true,
    factory: () => new MyTrigger());
await using var con = ds.CreateConnection();

Triggers are database-wide and apply now and after the database is opened; they are registered on the data source, not through SQL CREATE TRIGGER (which is not ported). The predicate receives the raw stored schema and table names.

Random and UUID generators

((IH2Extensions)con).RegisterRandomGenerator(seed => new Random((int)seed));
((IH2Extensions)con).RegisterUuidGenerator(version => Guid.NewGuid());
