Connection strings

Both spellings are accepted, because a caller will use whichever their code base already has. The jdbc:h2: prefix is stripped and not re-added, so Data Source=mem:x and Data Source=jdbc:h2:mem:x open the same database — the name itself is kept byte for byte, because the name decides which database is opened.

Data Source=mem:mydb                       // ADO.NET spelling
Data Source=jdbc:h2:mem:mydb              // H2 spelling, same database

new H2ConnectionStringBuilder("jdbc:h2:mem:mydb").ToH2ConnectionString()

Registration

services.AddDbConnectionFactory<H2ProviderFactory>(_ => new H2ProviderFactory());
// or construct directly:
await using var con = new H2Connection("jdbc:h2:mem:mydb");

Not implemented yet

Honest list — these throw TODOException or are absent, by design at this stage:

  • Transactions — BeginTransaction is not reachable: H2Connection.BeginDbTransaction throws TODOException. The H2Transaction type exists with Commit/Rollback/IsolationLevel, but nothing hands one out yet.
  • ChangeDatabase — throws TODOException.
  • GetSchema() over INFORMATION_SCHEMA — not there yet.
  • No DataAdapter and no CommandBuilder — explicitly unsupported by design, use Dapper or read the reader. CanCreateBatch is false.

See also Dapper for the live end-to-end flow, and port status for phases.
