H2Sharp.Shell client

A console SQL client over the engine, in the style of sqlite3. It runs SQL from the command line or interactively, against an in-memory or a file database. Source: tools/H2Sharp.Shell in the engine repository.

Build and run

dotnet build tools/H2Sharp.Shell/H2Sharp.Shell.csproj
dotnet run --project tools/H2Sharp.Shell -- [options] [dataSource]

After publishing, the executable is H2Sharp.Shell. The default data source is test, storage File.

Options

OptionDescription
-cs, --connection-stringFull H2Sharp connection string.
-d, --data-sourceDatabase file path or in-memory key.
--storage Memory|FileStorage kind. Default: File.
-sql, --sqlExecute SQL statements and exit.
-list, --listEnable result list mode.
-h, --help, -?Show help.

A positional argument is treated as the data source when no connection string is given.

Interactive commands

SQL statements must end with ;. Commands are case-insensitive.

CommandDescription
help, ?Show help.
listToggle table/list result mode.
maxwidth <n>Set maximum column width. Default: 100.
historyShow last 20 statements.
<number>Re-run a statement from history.
exit, quitClose connection and exit.

Examples

# one query
dotnet run --project tools/H2Sharp.Shell -- -sql "SELECT 1"

# several statements
dotnet run --project tools/H2Sharp.Shell -- -sql "CREATE TABLE t(a INT); INSERT INTO t VALUES (1),(2); SELECT * FROM t;"

# file database
dotnet run --project tools/H2Sharp.Shell -- test.db

# in-memory database
dotnet run --project tools/H2Sharp.Shell -- -d shell --storage Memory -sql "SELECT 1"

# full connection string
dotnet run --project tools/H2Sharp.Shell -- -cs "Data Source=demo;Storage=Memory" -sql "SELECT 1"
# interactive session
$ dotnet run --project tools/H2Sharp.Shell
sql> SELECT 1 AS x;
X
1
(1 row, 12 ms)
sql> list
Result list mode is now on
sql> SELECT 1 AS x, 2 AS y;
X: 1
Y: 2
(1 row, 8 ms)
sql> history
#1: SELECT 1 AS x, 2 AS y;
#2: SELECT 1 AS x;
sql> 2
SELECT 1 AS x;
X
1
(1 row, 5 ms)
sql> exit
Connection closed
