H2Sharp.PowerShell client

A PowerShell module over the engine, modelled on Invoke-SqliteQuery from PSSQLite. It provides Invoke-H2Query, which runs SQL and returns results as PowerShell objects. Source: tools/H2Sharp.PowerShell in the engine repository.

Build and import

dotnet build tools/H2Sharp.PowerShell/H2Sharp.PowerShell.csproj
Import-Module ./artifacts/bin/H2Sharp.PowerShell/debug/H2Sharp.PowerShell.psd1

Cmdlet: Invoke-H2Query

ParameterAliasesDescription
-Query-SqlSQL statement or batch to execute. Mandatory.
-Database-DataSource, -PathDatabase file path or in-memory key. Default: test.
-ConnectionStringFull H2Sharp connection string. Overrides -Database/-Storage.
-StorageFile or Memory. Default: File.
-ParametersHashtable of named parameters. Use $name in SQL.
-AsOutput format: PSObject, DataTable, SingleValue, None. Default: PSObject.
-NonQueryExecute as non-query and return affected row count.
-InputFileRead SQL from a file.

Examples

# basic query
Invoke-H2Query -Query 'SELECT 1 AS x'

# select properties
Invoke-H2Query -Query 'SELECT 1 AS x, 2 AS y' | Select-Object x, y

# in-memory database
Invoke-H2Query -Query 'SELECT 1 AS x' -Database shell -Storage Memory

# connection string
Invoke-H2Query -Query 'SELECT 1 AS x' -ConnectionString 'Data Source=demo;Storage=Memory'

# named parameters
Invoke-H2Query -Query 'SELECT $a + $b AS sum' -Parameters @{ a = 1; b = 2 }

# DataTable
$table = Invoke-H2Query -Query 'SELECT 1 AS x, 2 AS y' -As DataTable
$table.Rows

# single value
Invoke-H2Query -Query 'SELECT 1' -As SingleValue

# DDL/DML
Invoke-H2Query -Query 'CREATE TABLE t(a INT)' -NonQuery
Invoke-H2Query -Query 'INSERT INTO t VALUES (1),(2)' -NonQuery
Invoke-H2Query -Query 'SELECT * FROM t'

# read SQL from a file
Invoke-H2Query -InputFile .\script.sql

# file database
Invoke-H2Query -Query 'SELECT 1 AS x' -Database ./test.db
