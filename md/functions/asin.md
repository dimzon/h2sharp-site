# ASIN

> H2 `2.5.252` + H2Sharp pin `27c5170` · [Original](https://www.h2database.com/html/functions.html#asin) · © H2 Group (MPL-2.0 / EPL-1.0)

## Syntax

```bnf
ASIN([`numeric`](../grammar/numeric.md))
```

Calculate the arc sine.

Argument must be between -1 and 1 inclusive.

This function returns a double precision value.

## Example

```sql
ASIN(D)
```
