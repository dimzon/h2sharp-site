# ATAN2

> H2 `2.5.252` + H2Sharp pin `27c5170` · [Original](https://www.h2database.com/html/functions.html#atan2) · © H2 Group (MPL-2.0 / EPL-1.0)

## Syntax

```bnf
ATAN2([`numeric`](../grammar/numeric.md), [`numeric`](../grammar/numeric.md))
```

🟢 includes non-standard H2 syntax

Calculate the angle when converting the rectangular coordinates to polar coordinates.

This function returns a double precision value.

## Example

```sql
ATAN2(X, Y)
```
