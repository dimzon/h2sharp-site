# READONLY

> H2 `2.5.252` + H2Sharp pin `27c5170` · [Original](https://www.h2database.com/html/functions.html#readonly) · © H2 Group (MPL-2.0 / EPL-1.0)

## Syntax

```bnf
READONLY()
```

🟢 includes non-standard H2 syntax

Returns true if the database is read-only.

## Example

```sql
READONLY()
```
