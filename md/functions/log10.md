# LOG10

> H2 `2.5.252` + H2Sharp pin `27c5170` · [Original](https://www.h2database.com/html/functions.html#log10) · © H2 Group (MPL-2.0 / EPL-1.0)

## Syntax

```bnf
LOG10([`numeric`](../grammar/numeric.md))
```

Calculates the base 10 logarithm as a double value. Argument must be a positive numeric value.

## Example

```sql
LOG10(A)
```
