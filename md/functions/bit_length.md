# BIT_LENGTH

> H2 `2.5.252` + H2Sharp pin `27c5170` · [Original](https://www.h2database.com/html/functions.html#bit_length) · © H2 Group (MPL-2.0 / EPL-1.0)

## Syntax

```bnf
BIT_LENGTH([`bytes`](../grammar/bytes.md))
```

🟢 includes non-standard H2 syntax

Returns the number of bits in a binary string. This method returns a long.

## Example

```sql
BIT_LENGTH(NAME)
```
