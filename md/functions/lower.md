# LOWER

> H2 `2.5.252` + H2Sharp pin `27c5170` · [Original](https://www.h2database.com/html/functions.html#lower) · © H2 Group (MPL-2.0 / EPL-1.0)

## Syntax

```bnf
{ LOWER | { LCASE } } ( [`string`](../grammar/string.md) )
```

🔴 compatibility-only syntax

Converts a string to lowercase.

## Example

```sql
LOWER(NAME)
```
