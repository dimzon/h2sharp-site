# LN

> H2 `2.5.252` + H2Sharp pin `27c5170` · [Original](https://www.h2database.com/html/functions.html#ln) · © H2 Group (MPL-2.0 / EPL-1.0)

## Syntax

```bnf
LN([`numeric`](../grammar/numeric.md))
```

Calculates the natural (base e) logarithm as a double value. Argument must be a positive numeric value.

## Example

```sql
LN(A)
```
