# CURRENT_USER

> H2 `2.5.252` + H2Sharp pin `27c5170` · [Original](https://www.h2database.com/html/functions.html#current_user) · © H2 Group (MPL-2.0 / EPL-1.0)

## Syntax

```bnf
CURRENT_USER | SESSION_USER | SYSTEM_USER | USER
```

Returns the name of the current user of this session.

## Example

```sql
CURRENT_USER
```
