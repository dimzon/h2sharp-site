# COS

> H2 `2.5.252` + H2Sharp pin `27c5170` · [Original](https://www.h2database.com/html/functions.html#cos) · © H2 Group (MPL-2.0 / EPL-1.0)

## Syntax

```bnf
COS([`numeric`](../grammar/numeric.md))
```

Calculate the trigonometric cosine.

This function returns a double precision value.

## Example

```sql
COS(ANGLE)
```
