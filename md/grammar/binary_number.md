# Binary Number

> H2 `2.5.252` + H2Sharp pin `27c5170` · [Original](https://www.h2database.com/html/grammar.html#binary_number) · © H2 Group (MPL-2.0 / EPL-1.0)

## Syntax

```bnf
[+|-] {0b|0B} { [_] { 0-1 } [...] } [...]
```

A number written in binary notation.

## Example

```sql
0b101
0b_01010101_10101010
```
