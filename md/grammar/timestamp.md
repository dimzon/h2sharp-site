# Timestamp

> H2 `2.5.252` + H2Sharp pin `27c5170` · [Original](https://www.h2database.com/html/grammar.html#timestamp) · © H2 Group (MPL-2.0 / EPL-1.0)

## Syntax

```bnf
TIMESTAMP [ WITHOUT TIME ZONE ] '[-]yyyy-MM-dd hh:mm:ss[.nnnnnnnnn]'
```

A timestamp literal.

## Example

```sql
TIMESTAMP '2005-12-31 23:59:59'
```
