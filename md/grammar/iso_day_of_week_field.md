# ISO day of week field

> H2 `2.5.252` + H2Sharp pin `27c5170` · [Original](https://www.h2database.com/html/grammar.html#iso_day_of_week_field) · © H2 Group (MPL-2.0 / EPL-1.0)

## Syntax

```bnf
{ ISO_DAY_OF_WEEK } | { ISODOW }
```

🟢 includes non-standard H2 syntax 🔴 compatibility-only syntax

`ISO` day of week (1-7). Monday is 1.

## Example

```sql
ISO_DAY_OF_WEEK
```
