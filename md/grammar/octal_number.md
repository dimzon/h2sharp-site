# Octal Number

> H2 `2.5.252` + H2Sharp pin `27c5170` · [Original](https://www.h2database.com/html/grammar.html#octal_number) · © H2 Group (MPL-2.0 / EPL-1.0)

## Syntax

```bnf
[+|-] {0o|0O} { [_] { 0-7 } [...] } [...]
```

A number written in octal notation.

## Example

```sql
0o664
0o_123_777
```
