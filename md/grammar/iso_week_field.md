# ISO week field

> H2 `2.5.252` + H2Sharp pin `27c5170` · [Original](https://www.h2database.com/html/grammar.html#iso_week_field) · © H2 Group (MPL-2.0 / EPL-1.0)

## Syntax

```bnf
ISO_WEEK
```

🟢 includes non-standard H2 syntax

`ISO` week of year (1-53). `ISO` definition is used when first week of year should have at least four days and week is started with Monday.

## Example

```sql
ISO_WEEK
```
