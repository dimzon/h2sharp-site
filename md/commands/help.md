# HELP

> H2 `2.5.252` + H2Sharp pin `27c5170` · [Original](https://www.h2database.com/html/commands.html#help) · © H2 Group (MPL-2.0 / EPL-1.0)

## Syntax

```bnf
HELP [ anything [...] ]
```

🟢 includes non-standard H2 syntax

Displays the help pages of SQL commands or keywords.

## Example

```sql
HELP SELECT
```
