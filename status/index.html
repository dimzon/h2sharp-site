SQL that runs today

Each of these was landed as its own commit with a differential test against the reference JVM:

AreaWorks
QueriesFlat SELECT end to end, WHERE as index conditions, LIMIT/OFFSET/FETCH, ORDER BY served from indexes, DISTINCT
GroupingGROUP BY / HAVING through grouped execution
AggregatesCOUNT (incl. COUNT(*)), SUM, MIN, MAX (with the index first-or-last shortcut), AVG, STDDEV/VAR (Welford), ANY/EVERY, MEDIAN, ANY_VALUE, PERCENTILE_CONT/PERCENTILE_DISC via WITHIN GROUP, LISTAGG (three spellings), distinct aggregates
DML/DDLCREATE TABLE, INSERT, UPDATE, DELETE, parameters kept out of the SQL text
ExpressionsDUAL, CAST, NULL folding in AND/OR to UNKNOWN
