Correctness and performance notes

  • Decimals are exact or refused. NUMERIC round-trips exactly; overflow throws; a wide scale of zeros reads, a wide scale with a nonzero value throws — never a quiet round.
  • Hot paths cached. Indexes, sort types, row types and string reads; the session value comparer is cached instead of rebuilt per group.
  • Allocation-free where it shows. Typed getters in the reader, parameter scanning, windowed character reads; commands are closed after running so the query cache actually hits.

Open work

  • ChangeDatabase and connection-level GetSchema() over INFORMATION_SCHEMA.
  • No batches (CanCreateBatch is false) and no data-source enumerator.
  • Constraints and rights (phase 7), EF Core (9), the full conformance script suite (10).
  • Intervals reach .NET as TimeSpan only for DAY TO SECOND.
  • Public native engine surface is not promised yet.
