Port status

From the project's own docs/ROADMAP.md ↗ and README. The roadmap's Current status block is pinned to the commit it was written at, and new work lands after it — so this page quotes it, then adds what has landed since.

Status in one line: a usable subset runs end to end — an ADO.NET provider over an in-memory engine: open connection, DDL, DML, query, reader, Dapper.

Newer than the roadmap block

Verified in the source, not taken on trust from commit titles:

Landed after the roadmap refreshWhat it means
Predicates: BETWEEN, IN (list and constant set), LIKE, ILIKE, REGEXP, NOTPorted as the reference's own predicate types — BetweenPredicate, ConditionIn / ConditionInList / ConditionInConstantSet, CompareLike, ConditionNot — not a shortcut in the parser, and none of them refuses.
CASE, both formsSimpleCase and SearchedCase with OperationN.
Aggregates: JSON_ARRAYAGG, JSON_OBJECTAGG, HISTOGRAM, MODEJSON aggregates build straight into bytes; HISTOGRAM/MODE on a value-to-count map.
Window frame units, bound types, exclusionsThe frame machinery is ported. Window functions (OVER/FILTER) still are not.
UPDATE SET listBuilt from the reference's update-action array.
Row operations on a transactionDML runs on the session transaction with an internal savepoint, and DbTransaction auto-commit is fixed — so a rollback takes back what a statement did.
LIKE / REGEXP semanticsSemantics suites pass; the default LIKE escape and IN parameter binding were fixed.
Allocation workPooled page scratches, one Bits.Reverse for the MVStore byte helpers, the pattern Regex cached once, digit appends without an intermediate string.

Not yet

So the SQL mirror is not a promise about what runs — it documents H2's full grammar, while the engine executes the subset above:

  • JOIN, subqueries, window functions (OVER/FILTER), MERGE, MERGE USING, EXPLAIN — the window frame machinery is ported, window functions are not
  • The SAVEPOINT statement — row operations use an internal savepoint, which is not the SQL command
  • Sequences in DDL; the INFORMATION_SCHEMA catalogue
  • File databases and async OpenAsync — in-memory only today
  • Constraints and rights, EF Core
