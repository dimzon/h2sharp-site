# Railroad track sprites

`div-*.png` — track tiles for SQL railroad diagrams, source:
`https://www.h2database.com/html/images/` (© H2 Group, MPL-2.0 / EPL-1.0),
one-time download 2026-10-13.

Recolored for the dark theme by `tools/recolor-sprites.py`
(black-on-white → `#7c97c6` track color on transparent, AA preserved).
`orig/` keeps the untouched upstream files. Re-running the script is a no-op
while `orig/` exists.
